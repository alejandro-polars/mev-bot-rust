# mev-bot-rust

A MEV (Maximal Extractable Value) bot written in Rust for detecting and executing arbitrage and sandwich attacks on Ethereum-like blockchains.

IMPORTANT: This repository is an experimental "vibe coding" project — a quick, personal exploration and learning exercise. It is NOT production-ready, NOT audited, and should NOT be used with real funds.

Purpose: Educational experimentation and prototyping (vibe coding), not a finished product.

Safety: Do not run this against mainnet wallets with real funds. Use only on testnets or in isolated, local setups.

Risk: This is not financial or security advice. Use at your own risk.

See `.env.example` for configuration used in local testing.
